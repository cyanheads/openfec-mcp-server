# 0.9.2 — 2026-10-25

## Changed

- **Framework error text** escapes Markdown punctuation through mcp-ts-core 0.13.16; structured error messages keep literal text.
- **Framework startup configuration** rejects fractional ports and out-of-range counts or timers with diagnostics naming the environment variable (0.13.16).
- **Framework cancellation and HTTP shutdown** inherit 0.13.16's cancellation settlement and draining fixes, including `503` responses with `Retry-After` during shutdown.
- **Framework diagnostics** inherit bounded Zod issues and one-line ZodError log summaries from 0.13.15, failure-payload log rate-limit exemptions, and 0.13.16's broader secret-name redaction.
- **Development tooling** attributes shared audit advisories against the installed root dependency version; development references and release guidance are synchronized with the framework.
- **Hosted-client setup** documents Claude Code, Cline, Cursor and Claude Desktop connection shapes; runtime badges and Docker build examples match the current dependencies.
