# 0.9.1 — 2026-10-08

## Changed

- **Tool arguments are repaired before validation.** A numeric string sent to a number field (`per_page: "5"`, `cycle: "2024"`) is converted to the number and `null` for an optional field is treated as omitted (mcp-ts-core 0.13.14); an integer sent to a string field becomes its digits (0.13.9). A boolean sent to a string field, or a non-numeric string to a number field, is still rejected with `-32602` `invalid_arguments`.
- **Tool error results end with `request <id>`** and carry `data.requestId` (mcp-ts-core 0.13.10).
- **MCP SDK transport** (mcp-ts-core 0.13.9): a 2026-07-28 POST without `MCP-Protocol-Version` is refused `400` / `-32020`, a JSON-RPC batch over 100 messages is refused, and on stdio, stdin EOF aborts in-flight requests.
- **`ctx.recoveryFor` forwards removed from every `ctx.fail` site** in the tool and resource definitions. Internal: the framework now fills each declared `errors[]` recovery hint itself (mcp-ts-core 0.13.10), so the hints callers receive are unchanged. Tests assert failures through `runToolContract` (`tests/mcp-server/tools/definitions/contract-failure.ts`).
- **`server.json` npm entries drop the `run start:*` arguments and use `runtimeHint: "npx"`**, and the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `http` (mcp-ts-core 0.13.11).
- **Docker**: production dependencies install in a `deps` stage on the build platform and cross-install for the target, so multi-arch builds no longer run Bun under QEMU (0.13.10); musl-only native packages are pruned (0.13.11); base images move to Bun 1.4.2 (0.13.7). The image creates writable `.cache` and `.mirror` directories for the `bun` user and no longer sets `MCP_FORCE_CONSOLE_LOGGING`; `.dockerignore` excludes every `.env*` file and the MCP Registry token files.
- **`package.json`**: `rebuild` runs `scripts/build.ts` directly, `test` runs `vitest run`, `start:stdio` and `start:http` run `node dist/index.js`, `bundle` packs with `npx`, `files` excludes `dist/*.mcpb`, and `packageManager` is `bun@1.4.2`.
- **Package description reworded** across `package.json`, `manifest.json`, both plugin manifests, `CITATION.cff`, and the README: "Access FEC campaign finance data on candidates, money trails, and election filings via MCP. STDIO or Streamable HTTP."
- **Repo files re-synced to the framework template**: `.env.example` lists the new framework variables, `.gitignore` and `.mcpbignore` gain patterns (`.env*` with `.env.example`/`.env.template`/`.env.sample` kept, `.vscode/*`, and `docs/idea.md`, `logs/`, `.cache/`, `coverage/`, `tests/` excluded from the bundle), `.github/workflows/codeql.yml` analyzes `actions` and `javascript-typescript` as separate matrix jobs, `CLAUDE.md` and `AGENTS.md` follow the current agent protocol, and `scripts/` and `framework-skills/` match mcp-ts-core 0.13.14 (new `scripts/install-otel.ts`, `scripts/prune-musl-packages.ts`).
