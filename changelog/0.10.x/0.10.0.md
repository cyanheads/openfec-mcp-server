# 0.10.0 — 2026-10-28

## Added

- **`openfec-guide`** is served at `skill://openfec-guide/SKILL.md` for campaign-finance research and coverage checks.
- **Agent Plugins manifests** provide the root `plugin.json` and `mcp.json` pair alongside the existing client overlays.

## Changed

- Adopt mcp-ts-core 0.13.17's HTTP request-signal cleanup and 0.13.18's inline-code rendering for legal-search retrieval guidance.
- **Framework guidance and tooling** sync published-skill validation, plugin checks, bundle exclusions, and the bug-report Environment table.
- **Getting started** leads with hosted and local commands, with Docker and source setup under Running the server.
- **Published skills** ship through npm, Docker, and MCPB; the package allowlist excludes built MCPB archives.
- **Dependency release age** is one day, matching the framework template.

## Fixed

- **MCPB cleanup** preserves runtime SDK `dist/ext/skills` modules while removing package-root dependency agent documentation, with paired packaging regression tests ([cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
- **MCPB packaging** excludes repository-only paths, node-gyp build output, and framework build-only files.
