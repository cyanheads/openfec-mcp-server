# 0.10.1 — 2026-11-12

## Changed

- **`campaign-analysis` prompt and `openfec-guide` skill (1.1)** direct the trajectory call to omit `cycle` and set `per_page` to 100, and to label each row by its own `committee_type` and `committee_name` (#54).
- **`FEC_API_KEY` descriptions** (config, `.env.example`, README, `manifest.json`, `server.json`, `.claude-plugin/plugin.json`) describe `DEMO_KEY` as a small daily allowance shared per IP, with no hourly figure (#51).
- **mcp-ts-core 0.13.22** keeps OpenFEC's JSON error bodies on `structuredContent.error.data`, but HTML and plain-text error bodies from the edge no longer reach it.

## Fixed

- **`openfec_get_committee_totals`** with `cycle` omitted (single mode) now returns the committee's cycles across changes of committee type; it previously returned only the newest type's (`C00703975` returned 2026 alone) (#54). A failed history-driven read, other than a rate limit or cancellation, returns the rows read with a `notice` naming the missing cycles, and OpenFEC's 404 on the history reads as an empty history.
- **429 errors** name the wait OpenFEC reported, and on `DEMO_KEY` point to a personal `FEC_API_KEY`, in place of "Wait a moment and retry" (#51).
- **A 2xx answer that is not an OpenFEC envelope** (an HTML page served with 200, or JSON without a `results` array, `"results": null` included) is retried and reported as `ServiceUnavailable`. An HTML page previously failed as a `ValidationError` quoting the page, `"results": null` threw a `TypeError`, and an exhausted retry surfaced as an internal error.
