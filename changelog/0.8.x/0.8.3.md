# 0.8.3 — 2026-09-23

## Added

- **`district`** filter on `openfec_lookup_calendar`'s `election_dates` mode narrows to one House district (sent upstream as `election_district`, zero-padding a lone digit); at-large races carry no district upstream and never match it. The outbound parameter allowlist now covers `/election-dates/`. ([#41](https://github.com/cyanheads/openfec-mcp-server/issues/41))
- **Election resources** (`openfec://election/{cycle}/{office}...`) carry an `empty_result_notice` on a zero-candidate race, and each template's `office` enum rejects other codes with a message naming the sibling template that serves them. ([#37](https://github.com/cyanheads/openfec-mcp-server/issues/37))

## Changed

- **`openfec_campaign_analysis`** and **`openfec_money_trail`** now resolve a cycle's principal committee from `openfec_lookup_elections`'s `candidate_pcc_id` instead of `openfec_search_committees`' `designation=P`, which reflects only each committee's current designation and drops a committee since redesignated; `openfec_search_committees`' `designation` description points there too. ([#39](https://github.com/cyanheads/openfec-mcp-server/issues/39))
- **`openfec://candidate/{candidate_id}`**'s description now says `principal_committees` reflects current designation with no cycle, and points at `openfec_lookup_elections`' `candidate_pcc_id` for a given cycle's committee. ([#45](https://github.com/cyanheads/openfec-mcp-server/issues/45))

## Fixed

- **`openfec://committee/{committee_id}`** now fails the read when its totals fetch rejects (rate limit, timeout, malformed response) instead of silently resolving with the financial fields missing. ([#33](https://github.com/cyanheads/openfec-mcp-server/issues/33))

## Dependencies

- `@types/node` 26.6.1 → 26.6.2
