# 0.8.1 — 2026-09-19

## Changed

- **`createApp()`** now declares `sessionMode: 'stateless'` directly, so a deployment that sets no `MCP_SESSION_MODE` resolves stateless instead of `auto` → stateful. An explicit `MCP_SESSION_MODE` still overrides it; the published container is unaffected, since it already pinned `stateless`. The resolved mode is also carried on `/.well-known/mcp.json` under `_meta` key `io.github.cyanheads.mcp-ts-core/sessionMode`.
- **Argument rejection** now returns `isError: true` with `structuredContent.error` at code `-32602`, `data.reason: "invalid_arguments"`, and a synthesized `Recovery:` line naming the accepted root keys or expected type — previously a bare text block with no `structuredContent`.
- **Parameter aliasing**: a parameter sent in another case style now reaches its declared key (`perPage`, `Per-Page`, `PER_PAGE` all resolve to `per_page`); client-added root keys (`toolCallId`, `tool_call_description`, `_meta`, `_`-prefixed keys) are dropped rather than rejected. Calls that previously failed as `Unrecognized key` now succeed.
- Tool error text now closes with a `(reason <reason>)` clause.
- **`FEC_API_KEY`** read as empty or as an unsubstituted `${user_config.FEC_API_KEY}` placeholder now falls back to `DEMO_KEY`, not just when the variable is absent.
- **`.claude-plugin/plugin.json`** collects `FEC_API_KEY` through a `userConfig` prompt and forwards it as `${user_config.FEC_API_KEY}`; **`.codex-plugin/mcp.json`** forwards it via `env_vars`. Both previously wrote a blank `""` literal, which overwrote a user's exported key.

## Fixed

- **`openfec_get_legal_document`**'s `legal_document_not_found` contract's `when` field, truncated mid-sentence since it was written.
- **An upstream 500** now classifies `ServiceUnavailable` rather than `InternalError`; a 501's in-band `retryable: false` keeps it out of the retry ladder (previously retried three times).
